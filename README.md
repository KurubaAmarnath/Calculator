# Simple Calculator

A simple and user-friendly calculator built using **HTML, CSS, and JavaScript**. This project performs basic arithmetic operations with a clean and responsive interface.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Clear button
- Delete button
- Decimal calculations
- Responsive design
- Interactive buttons

## Technologies Used

- HTML5
- CSS3
- JavaScript
